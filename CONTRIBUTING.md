# Contributing

This repository is part of [Compute Central](https://computecentral.in/) and is
**personally maintained. External contributions are not accepted.**

- Pull requests from outside collaborators will be closed without review or merge.
- Please do not submit content, corrections, or feature requests as pull requests.

The code is MIT licensed, so you are free to fork it, change it, and use it in
your own work without asking. That is the intended way to build on this.

If you find a security issue, report it privately as described in
[SECURITY.md](SECURITY.md). Do not open a public issue.
